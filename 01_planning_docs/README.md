## Document Philosophy

This integration repo operates at a **higher abstraction level** than tool development repos:
- **Tool repos** = Agile sprints, active development
- **Integration repo** = Episodic validation, assembly

Therefore:
- No sprint planning (see Roadmap phases instead)
- No active backlogs (see Tool Catalog instead)
- Focus on integration patterns, not tool development
